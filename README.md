# 财务专用 PDF 合成与智能压缩助手 (Finance PDF Tool)

一款专为财务、会计及行政人员打造的轻量级 Windows 原生图片转 PDF 桌面工具。支持凭证、发票、水单、税务报表批量无损合成与智能政务申报压缩。

## ✨ 核心特性

- **绿色单文件运行**：无任何第三方环境依赖，基于 Windows 系统自带的 .NET Framework 运行，随拷随用。
- **拟真纸张所见即所得预览**：内置 A4 / A3 纸张立体投影预览，实时呈现页面排版、方向旋转与留白边距。
- **专为财务排版优化**：
  - **小票据自动居中**：交易回单、报销小票在 A4 纸正中央规整居中，预留舒适装订边距，杜绝拉伸变形。
  - **自由版式调节**：支持标准 A4、标准 A3、自适应原图尺寸（1:1 无白边），以及纵向、横向和智能方向。
- **画质与智能压缩**：
  - **⭐ 政务申报模式**：文件体积缩减约 70%，针对红章、发票号码、数字金额进行高保真边缘增强，轻松通过电子税局及网银系统限制。
  - **💎 原画无损模式**：100% 原始画质直出封装，零重编码，适合重要凭证永久归档。
- **绝对安全离线**：纯本地内存离线运算，完全不联网，彻底杜绝企业涉税及财务凭证数据外泄。

## 🛠️ 编译方式

无需安装 Visual Studio 等大型开发软件，双击目录下的 一键重新编译.bat 即可直接调用 Windows 自带的编译器（C# Compiler）秒级生成可执行文件。
