# 财务专用 PDF 转换器 (Finance PDF Tool)

一款专为财务、会计及行政人员打造的轻量级 Windows 原生图片与 PDF 互转桌面工具。不仅支持凭证、发票、水单、税务报表批量无损合成与智能政务压缩，还新增了基于 Windows 10/11 硬件加速引擎的高清 PDF 转图片功能。

---

## ✨ 核心特性

### 1. 📄 图片合成 PDF
- **拟真纸张所见即所得预览**：内置 A4 / A3 纸张立体投影预览，实时呈现页面排版、方向旋转与留白边距。
- **专为财务排版优化**：
  - **小票据自动居中**：交易回单、报销小票在 A4 纸正中央规整居中，预留舒适装订边距，杜绝拉伸变形。
  - **自由版式调节**：支持标准 A4、标准 A3、自适应原图尺寸（1:1 无白边），以及统一竖版、统一横版和智能方向。
- **画质与智能压缩**：
  - **⭐ 政务申报模式**：文件体积缩减约 70%，针对红章、发票号码、数字金额进行高保真边缘增强，轻松通过电子税局及网银系统限制。
  - **💎 原画无损模式**：100% 原始画质直出封装，零重编码，适合重要凭证永久归档。

### 2. 🖼️ PDF 提取图片（新增）
- **原生高性能渲染**：基于 Windows 10/11 内置硬件加速渲染引擎，无需安装任何外部第三方软件或庞大运行库。
- **双格式自由切换**：
  - **⭐ PNG 高清无损**：公章发票纤毫毕现，无任何压缩伪影，财务核对首选。
  - **📁 JPG 通用轻量**：体积轻巧，适合微信、钉钉或邮件快速传输。
- **三档专业清晰度（DPI）**：
  - **300 DPI 超清打印**：3x 高精采样，发票数字、细小文字与公章细节极清。
  - **150 DPI 高清阅读**：1.5x 适中倍率，兼顾画质与文件体积。
  - **96 DPI 标准轻量**：1x 屏幕原生尺寸，极速导出。
- **灵活导出范围**：支持全部页面一键导出、自定义勾选指定页面导出、仅导出当前预览页。
- **实时大图翻页预览**：快速查看 PDF 各页内容与详细尺寸。

### 3. 🔒 纯绿色单文件与绝对安全离线
- 单文件绿色运行，解压即用，不修改注册表。
- 纯本地内存离线运算，完全不联网，彻底杜绝企业涉税及财务凭证数据外泄。

---

## 🛠️ 编译方式

无需安装 Visual Studio 等大型开发软件，双击目录下的 `一键重新编译.bat` 即可直接调用 Windows 自带的编译器（C# Compiler）秒级生成可执行文件。
